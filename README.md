# T Text Studio

T Text Studio is a Windows desktop application for collecting available video captions and transcripts, with optional cloud audio transcription when a text track is unavailable or when you choose to transcribe.

## Download for Windows

Open the **Releases** section and download one of the attached files:

- **Setup.exe:** Installs the application.
- **Portable.zip:** Extract the full ZIP and run `TTextStudio.exe` inside the extracted folder.

Do not use GitHub's **Code → Download ZIP** to install the application. That ZIP contains this downloads repository, not the program.

## Before you start

Some sources may require access or may not provide captions. Cloud transcription requires your own supported API key and sends selected audio to the configured provider. Check the release notes for the current beta status.

## Feedback

If something fails, include the application version, source type, selected action, and error message. Never post an API key, browser cookies, or a private recording in a public issue.

This repository contains public download information and release files. The development source is maintained separately.
